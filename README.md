## ⚡ Performance & Engineering Highlights

This repository contains the complete, high-performance portfolio website for Balasubramanian PG, engineered from the ground up for sub-second load times, accessibility, and modern responsive design.

| Metric | Legacy Website | Rewritten Architecture | Improvement |
| :--- | :--- | :--- | :--- |
| **Initial Network Transfer** | **~56.4 MB** | **< 200 KB** (above fold) | **99.6% reduction** |
| **Total Media Size** | 53.21 MB (20 raw JPEGs) | 2.52 MB (27 WebP assets) | **95.3% reduction** |
| **CSS Footprint** | ~1.77 MB (7 files, Bootstrap 4, helpers.css) | **~15 KB** (single modular `main.css`) | **99.1% reduction** |
| **JavaScript Weight** | ~230 KB (jQuery, Bootstrap, Slick, etc.) | **~4.8 KB** (vanilla ES module) | **Zero 3rd-party dependencies** |
| **Artificial Delay** | 700 ms (`#pb_loader` timeout) | **0 ms** (instant render) | **Eliminated** |
| **Typography** | Render-blocking icon font packs | Raleway &amp; Quicksand (`font-display: swap`) | **Zero layout shift (`CLS: 0`)** |

## 🚀 Running Locally

To run this website locally, simply serve the root directory with any static HTTP server:

```bash
# Using Python
python -m http.server 3000

# Using Node (npx)
npx serve .
```

Open `http://localhost:3000` in any modern web browser.
